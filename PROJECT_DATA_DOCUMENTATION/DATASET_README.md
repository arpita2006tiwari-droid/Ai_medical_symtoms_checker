# AI Medical Symptom Checker - Dataset Documentation

This folder contains all datasets, vocabularies, ontologies, and model artifacts extracted from the AI Medical Symptom Checker project. It is structured for read-only presentation, analysis, and validation.

## Files Provided

### 1. Training & Inference Datasets
*   **01_Original_Kaggle_Dataset.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 4920 / 18
    *   **Origin**: Kaggle dataset. (Copied from `ml/data/raw/dataset.csv`).
    *   **Purpose**: Original dataset mapping a primary `Disease` to wide columns `Symptom_1` through `Symptom_17`.
    *   **Target Column**: `Disease`
    *   **Status**: Original, Unprocessed.
*   **02_Processed_Training_Dataset.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 304 / 132
    *   **Origin**: Feature matrix generated by `ml/src/preprocess.py`. (Copied from `ml/data/processed/processed_symptom_dataset.csv`).
    *   **Purpose**: The actual dataset passed to Scikit-Learn for training. Contains exact duplicate cases dropped, and wide symptoms flattened into a sparse, one-hot encoded format.
    *   **Target Column**: `Disease`
    *   **Status**: Processed/Transformed.

### 2. Model Vocabularies & Artifacts
*   **03_Symptom_Vocabulary.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 131 / 2
    *   **Origin**: Extracted dynamically from `ml/artifacts/symptom_vocabulary.json`.
    *   **Purpose**: The exact, ordered list of unique symptoms the machine learning model was trained to recognize as features. 
    *   **Status**: Generated from dataset processing.
*   **04_Symptom_Ontology.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 73 / 4
    *   **Origin**: Extracted directly from Python code at `backend/app/services/symptom_ontology.py`.
    *   **Purpose**: Maps canonical symptoms to clinical categories (e.g., Neurological) and lists natural-language synonyms for the NLP extraction engine.
    *   **Status**: Developer-generated (Hardcoded).
*   **05_Model_Feature_Names.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 131 / 2
    *   **Origin**: Deserialized array `rf_model.feature_names_in_` from the saved model object `ml/models/symptom_random_forest.joblib`.
    *   **Purpose**: Model Metadata. Proves the feature space exactly matches the vocabulary.
    *   **Status**: Model Metadata.
*   **06_Model_Disease_Classes.csv**
    *   **Format**: CSV (UTF-8)
    *   **Rows / Cols**: 41 / 2
    *   **Origin**: Deserialized array `rf_model.classes_` from the saved model object `ml/models/symptom_random_forest.joblib`.
    *   **Purpose**: Model Metadata. Lists the 41 unique disease conditions the model was trained to predict.
    *   **Status**: Model Metadata.

### 3. Medical Context Metadata (Kaggle Supplements)
*   **07_Kaggle_Symptom_Descriptions.csv**: (41, 2) Maps a `Disease` to a text paragraph description. Copied from `ml/data/raw/symptom_Description.csv`.
*   **08_Kaggle_Symptom_Severities.csv**: (133, 2) Maps a `Symptom` to a subjective severity weight. Copied from `ml/data/raw/Symptom-severity.csv`.
*   **09_Kaggle_Symptom_Precautions.csv**: (41, 5) Maps a `Disease` to four recommended precaution steps. Copied from `ml/data/raw/symptom_precaution.csv`.

## Limitations
*   The `.joblib` random forest file was not exported as a CSV because it contains thousands of binary decision tree nodes rather than tabular data.
*   Application user data (login credentials, test logs, conversation history) residing in PostgreSQL was explicitly excluded to protect data isolation policies and PII.
